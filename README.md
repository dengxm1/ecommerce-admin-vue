# 《全栈项目技术白皮书》

## 前端

**基于 RBAC 的动态权限管理系统**：实现了从后端动态加载菜单和按钮权限，通过自定义指令 `v-permission` 进行**按钮级细粒度控制**，同时利用动态路由机制动态添加路由表，保证了前端权限与后端配置的实时同步。

**WebSocket 实时消息推送**：封装了基于 **SockJS + STOMP** 的 WebSocket 服务，支持断线重连、心跳检测、事件订阅，并集成了桌面通知与 Element Plus 弹窗提醒，实现了系统公告、个人通知的实时推送。

**高度可复用的业务组件库**：自主封装了 **ProTable、ProForm、ProUpload、ProFormDialog** 等通用组件，通过配置式 API 大幅提升 CRUD 页面的开发效率，同时支持插槽扩展，兼顾灵活性与一致性。

**前端工程化与类型安全**：使用 **TypeScript 严格模式**编写，对所有 API 响应、Vuex store、组件属性进行完整类型声明；采用 **Vite** 构建，配置了路径别名、代理转发，并集成 Prettier 统一代码风格。

**滑块验证码组件**：实现了前后端联动的**滑动拼图验证码**，支持验证码刷新、失败重试、失败次数限制，增强了登录安全性。

**多 Tab 标签页管理**：基于 **Vue Router** 实现了多标签页导航，支持标签页的添加、关闭、刷新，并利用 **Pinia** 持久化标签状态，提升了多页面操作的便捷性。

**Pinia 模块化状态管理**：将用户、权限、角色、标签页、通知等状态拆分为独立的 store，逻辑清晰且易于维护，同时利用 **computed** 和 **watch** 实现响应式联动。

**响应式布局与主题定制**：采用 **SCSS 变量 + CSS 渐变**设计，适配暗色模式（部分），并针对移动端做了简单的响应式适配，提升多端体验。

## 后端

**1. 基于 RBAC 的精细化权限控制系统**  
实现完整的**角色-菜单-按钮三级权限模型**，菜单数据静态初始化，通过 `system_menu` 表预定义所有目录、菜单和按钮。  
自定义注解 `@RequiresPermissions` 和 `@PassToken`，结合 **JWT 拦截器**实现接口级权限验证，支持 **AND/OR 逻辑组合**，并能自动放行白名单接口。  
权限数据在后端集中管理，前端根据接口返回的权限标识动态渲染菜单和按钮，确保前后端权限同步。

**2. 多租户架构预留设计**  
数据库表均包含 `tenant_id` 字段，并设置外键约束，为未来升级到 **SaaS 多租户平台**打下基础。  
设计租户内唯一约束（如 `(tenant_id, username)`），保证数据隔离的同时支持多商户扩展。  
在初始化脚本中只创建一个默认租户，但代码中已完整支持租户ID传递（从 JWT 中解析并存入请求属性），后续只需扩展租户管理即可平滑升级。

**3. WebSocket 实时消息推送与在线统计**  
基于 **Spring WebSocket + STOMP 协议**实现实时消息服务，支持系统公告广播、个人通知点对点推送。  
自定义 `WebSocketAuthInterceptor` 在握手阶段解析 JWT，将用户信息存入会话，实现用户维度的消息订阅。  
实时统计在线人数，通过内存中的 `ConcurrentHashMap` 维护用户会话，并在人数变化时广播给所有在线用户。

**4. 自定义滑块验证码组件**  
不依赖第三方服务，**纯 Java 实现滑动拼图验证码**，包括背景图随机选取、拼图形状生成（圆/凸起/凹进）、缺口定位和容差验证。  
使用内存缓存（`ConcurrentHashMap`）存储验证码信息，并设置过期自动清理，防止内存泄漏。  
前端组件与后端无缝配合，增强登录/敏感操作的安全性。

**5. 文件上传与缩略图生成**  
封装统一的文件上传服务，支持单文件/多文件上传、按业务类型分类存储（如 `user_avatar`、`product_image`）、按日期分层目录。  
集成**缩略图生成**功能，对上传的图片自动创建指定尺寸的缩略图，并返回访问 URL。  
通过 `FileUploadConfig` 配置本地文件路径映射，实现静态资源访问，支持后续迁移到 OSS。

**6. Excel 数据导出与自定义列宽**  
基于 **Apache POI** 封装 `ExcelExportUtil` 工具类，支持任意数据列表导出，通过注解或字段名映射表头。  
支持**自定义列宽**，可根据字段内容动态设置列宽，提升导出文件的可读性。  
在用户管理模块实现数据导出功能，支持按筛选条件导出当前列表数据。

**7. 数据库设计与性能优化**  
设计了完整的关系模型：用户、角色、菜单、角色菜单、用户角色、通知、用户通知关联表，满足复杂权限和消息场景。  
使用**组合唯一键**保证租户内数据唯一性（如 `(tenant_id, username)`），利用外键约束维护数据一致性。  
针对查询频繁的字段建立索引（如 `user_id`、`tenant_id`、`create_time`），并通过 **MyBatis 动态 SQL** 实现多条件分页查询。

**8. 统一响应与异常处理**  
定义统一的 `ApiResponse` 泛型类，规范所有接口返回格式（code、message、data），便于前端统一处理。  
在 Service 层抛出自定义异常，由 Controller 层捕获并转换为标准错误响应，避免异常信息泄露。

**9. JWT 身份认证与安全控制**  
使用 **JJWT** 生成和验证 Token，包含用户ID、用户名、租户ID等关键信息，并设置过期时间。  
在拦截器中解析 Token 并将用户信息存入 Request 属性，供后续 Controller 直接使用，避免重复解析。  
对登录、验证码等接口使用 `@PassToken` 放行，其他接口默认拦截，确保系统安全。

**10. 清晰的代码分层与模块化**  
遵循 **Spring Boot 标准分层**：Controller（接口层）、Service（业务层）、Mapper（数据层）、Entity（实体）、DTO（数据传输对象），职责清晰。  
使用 **Lombok** 简化代码，通过 **Slf4j** 记录关键日志，便于问题追踪。  
配置文件分离（`application.properties`），支持多环境部署。
